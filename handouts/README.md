# Handouts

This folder contains several handouts given in ME 50900 lectures.

For example:

* [Writing tips and best practices for assignments](writing_best_practice_tips_.md) &mdash; technical writing tips, including for using LaTeX, and best practices for preparing assignment solutions.
* [Vector and tensor algebra summary](tensor_algebra.md) &mdash; a handy summary and tips regarding the key algebraic operations (transpose and various multiplications) we perform with vectors and tensors in index notation.
* [iNS summary sheet](iNS_summary_sheet.pdf) &mdash; a handy summary of the governing equations (conservation of mass and conservation/balance of linear momentum for a continuum in the Eulerian frame) and the Newtonian fluid's stress tensor (for compressible and incompressible flow).
* [Ideal flows handbook](ideal_flows_handbook.pdf) &mdash; a handy summary of the building block ideals flows in the plane (2D), from which we generate many others by superposition.
* [Lubrication theory summary](lubrication_summary.pdf) &mdash; a handy compare/contrast of unidirectional flows and lubrication flows, highlighting similarities/differences in the solution approach to basic problems.
* [Fun web resources](fun_web_resources.md) &mdash; fluid mechanics demonstrations, as well as YouTube channels you can follow that post such videos.
