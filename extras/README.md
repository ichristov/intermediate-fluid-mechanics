# Extras

This folder contains notebooks illustrating fun fluid mechanics topics that are not always covered in ME 50900. They are for your enrichment. :gift:

Feel free to explore:
* [Flow Visualization](Flow_Visualization.ipynb) &mdash; quiver plots, streamlines, pathlines, streaklines
* [Asymptotic Suction Flow](Asymptotic_Suction_Flow.ipynb) &mdash; a fully-developed flow field with two velocity components
* [Startup PC Flow](Startup_PC_Flow.ipynb) &mdash; the full transient solution from rest for Poiseuille&ndash;Couette flow (to complement [Combined PC Flow](../Combined_PC_Flow.ipynb))
* [Rectangualr Duct](Rectangular_Duct.ipynb) &mdash; Fourier series solution for pressure-driven flow in a 3D duct
* [Slip Flow Channel](Slip_Flow_Channel.ipynb) &mdash; a pressure-driven flow with Navier slip in a 2D channel, arising from microfluidics
* [Womersley Flow](Womersley_Flow.ipynb) &mdash; flow in a 2D channel and a 3D axisymmetric tube driven by a periodically pulsating pressure gradient, including animations

Enjoy. Cheers! :beer:
