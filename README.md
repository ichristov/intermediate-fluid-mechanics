# ME 50900 &ndash; Intermediate Fluid Mechanics

This is a GitHub repository for ME 50900 &ndash; Intermediate Fluid Mechanics at Purdue University, as taught by Prof. [Ivan C. Christov](HTTPS://christov.tmnt-lab.org).
The repository mainly consists of Jupyter notebooks used for hands-on demos in lectures, continuous knowledge acquisition, problem-set solutions, and enrichment activities.

:rocket: Getting started (rough grouping of notebooks based on course topics):
* Kinematics:
    - [Flow Visualization](extras/Flow_Visualization.ipynb) &mdash; quiver plots, streamlines, pathlines, streaklines
    - [Velocity Field in Polar Coords](Velocity_Field_in_Polar_Coords.ipynb) &mdash; plotting planar (2D) velocity fields given in terms of polar velocity components
    - [Streamfunction 2D](Streamfunction_2D.ipynb) &mdash; constructing, visualizing, and understanding streamfunctions for 2D flows in Cartesian coordinates
    - [Kinematics Material Derivative](Kinematics_Material_Derivative.ipynb) &mdash; given a flow field, going beyond flow visualization
* Dynamics of unidirectional flows:
    - [Combined PC Flow](Combined_PC_Flow.ipynb) &mdash; solution of combined Poiseuille&ndash;Couette flow generated by the combination of a pressure gradient and wall motion
    - [Startup PC Flow](extras/Startup_PC_Flow.ipynb) &mdash; the full transient solution from rest for Poiseuille&ndash;Couette flow (to complement [Combined PC Flow](../Combined_PC_Flow.ipynb))
    - [Slip Flow Channel](extras/Slip_Flow_Channel.ipynb) &mdash; a pressure-driven flow with Navier slip in a 2D channel, arising from microfluidics
    - [Stokes' 1st Problem](Stokes_1st_Problem.ipynb) &mdash; similarity solution for the flow caused by the impulsive motion of a plate
    - [Stokes' 2nd Problem](Stokes_2nd_Problem.ipynb) &mdash; post-transient solution for the flow caused by an oscillating plate
    - [Decay Ideal Vortex](Decay_Ideal_Vortex.ipynb) &mdash; similarity solution for the decay of a point load of vorticity at the origin
    - [Womersley Flow](extras/Womersley_Flow.ipynb) &mdash; flow in a 2D channel and a 3D axisymmetric tube driven by a periodically pulsating pressure gradient, including animations
    - [Rectangular Duct](extras/Rectangular_Duct.ipynb) &mdash; Fourier series solution for pressure-driven flow in a 3D duct
* Flow fields with two velocity components:
    - [Asymptotic Suction Flow](extras/Asymptotic_Suction_Flow.ipynb) &mdash; a fully-developed flow field with two velocity components
    - [Ideal Flows 2D](Ideal_Flows_2D.ipynb) &mdash; having fun with functions of a complex variable
    - [Boundary Layers](Boundary_Layers.ipynb) &mdash; everything you need to know about Blasius' problem
    - [Stokes Flows 2D](Stokes_Flows_2D.ipynb) &mdash; having fun with the biharmonic equation in the plane, from Taylor's scraper to Moffatt's eddies
    - [Stokes Flow Past Sphere](Stokes_Flow_Past_Sphere.ipynb) &mdash; heavy-duty calculations in spherical coordinates
    - [Slipper Pad Bearing](Slipper_Pad_Bearing.ipynb) &mdash; a classic application of Reynolds' lubrication equation
* Dimensional analysis:
    - [Dimensional Analysis](Dimensional_Analysis.ipynb) &mdash; Buckingham's $\Pi$ theorem is just the rank&ndash;nullity theorem in disguise
    - [Taylor and the Bomb](Taylor_and_the_Bomb.ipynb) &mdash; how G. I. Taylor estimated the energetic yield of the Trinity test

:warning: The notebooks are unlikely to be robust and may require updates to run on different platforms, and as underlying Python libraries evolve.
